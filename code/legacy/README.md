# Legacy geometry library (archival only)

`library_final_0.9.116.lit` is the shared 7.3 KB / 200-line / 39-declaration
Litex geometry library used by the archived IMO runs. It is kept here only as
provenance for the claim “the archived solutions used a small self-built Litex
library.”

It uses the old Litex 0.9.x syntax (`p[1]` indexing). It is **not** expected to
load on Litex 1.x. For runnable code, use `../2D_Geometry/`.

The source in the archive is `../../../IMO/Litex/geo/library_final.lit`.
